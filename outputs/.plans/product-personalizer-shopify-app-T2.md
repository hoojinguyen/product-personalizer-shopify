# Research Task T2: Shopify App Architecture & Development Fundamentals

**Owner:** Researcher 2  
**Output:** `outputs/.drafts/product-personalizer-shopify-app-research-architecture.md`

## Objective
Understand Shopify's app architecture, development framework, and the step-by-step process to build and deploy a Shopify app.

## Scope

Research the following:

1. **Shopify App Architecture**
   - Typical architecture for Shopify apps (backend, frontend, data storage)
   - How apps authenticate with Shopify stores
   - OAuth flow and access scopes
   - Data ownership and privacy considerations

2. **Development Framework & Tools**
   - Official Shopify CLI and scaffolding tools
   - Recommended tech stacks (Node.js, React, etc.)
   - Development environment setup
   - Local testing and dev store requirements

3. **Key APIs for Shopify Apps**
   - Admin API (GraphQL/REST) for store management
   - Storefront API for headless commerce
   - Webhook system for real-time store events
   - Differences and use cases for each

4. **App UI Integration Points**
   - Admin UI Extensions (where to place custom admin UI)
   - Checkout UI Extensions (product customization at checkout)
   - Customer Account UI Extensions
   - Metafields and Metaobjects for custom data

5. **Development Workflow**
   - App creation and configuration
   - Local development and testing
   - Staging and production deployment
   - Monitoring and debugging

6. **App Store Submission & Requirements**
   - App Store listing and review process
   - Compliance and security requirements
   - Pricing models and billing integration
   - Support and documentation standards

## Search Strategy

- Start with official Shopify developer documentation (shopify.dev)
- Search for Shopify app architecture guides, tutorials, best practices
- Look for "build a Shopify app" step-by-step guides
- Check for recent changes or new APIs (2024-2026)
- Search for "Shopify CLI" and "Shopify app scaffold"
- Research app store review criteria and common rejections

## Output Format

Write a markdown file organized by topic. Include code examples where relevant, links to official docs, and distinctions between different approaches (Admin Extensions vs Checkout Extensions vs custom frontends, etc.).
