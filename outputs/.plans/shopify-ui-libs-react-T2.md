# Researcher 2: Alternative UI Libraries for Shopify Apps

**Objective**: Investigate modern alternative UI libraries (such as Shadcn UI, Tailwind CSS, Mantine, or Chakra UI) for building Shopify Admin apps.

**Key Areas to Cover**:
1. **Developer Experience**: How does building a Shopify app with Shadcn UI or Mantine compare to Polaris? 
2. **App Bridge Compatibility**: Can you still effectively use `@shopify/app-bridge-react` (for modals, toasts, title bars, navigation) while using a custom UI library for the rest of the layout?
3. **Tech Stack Compatibility**: How well do these alternatives play with React Router v7 and Vite? (Tailwind and Shadcn generally work great, but are there Shopify-specific gotchas?)
4. **Trade-offs**: What are the risks of *not* using Polaris? (e.g., app approval risks, visual inconsistency for merchants). Are there "Polaris-styled" Tailwind themes available?

**Tools to use**: `web_search` for community discussions, dev.to articles, Reddit threads, and GitHub templates regarding "Shopify app without polaris" or "Shopify app with tailwind shadcn".
**Output**: A detailed markdown report with findings and source URLs.
