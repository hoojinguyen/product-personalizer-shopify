# Research Task T1: Product Personalizer App Analysis

**Owner:** Researcher 1  
**Output:** `outputs/.drafts/product-personalizer-shopify-app-research-app.md`

## Objective
Understand the existing Product Personalizer app on the Shopify App Store. Analyze its features, functionality, use cases, limitations, and market position.

## Scope

Research the following:

1. **What is Product Personalizer?**
   - Official app description and purpose
   - Key features and capabilities
   - Supported product customization types

2. **How does it work?**
   - Customization workflow from customer perspective
   - Data it collects and stores
   - Integration points with Shopify stores
   - Pricing model (free, freemium, premium)

3. **Use Cases**
   - Common merchant use cases
   - Industries or product types it serves best
   - Customer testimonials or case studies if available

4. **Limitations & Gaps**
   - What it doesn't do
   - Known limitations or complaints from reviews
   - Competitive positioning vs other personalization tools

5. **Technical Context**
   - Tech stack if publicly documented
   - GitHub repository or open-source components
   - API integrations it uses

## Search Strategy

- Visit https://apps.shopify.com/product-personalizer directly
- Search for Product Personalizer reviews, use cases, tutorials
- Look for community discussions (Shopify forums, Reddit, etc.)
- Check GitHub for the app repo if public
- Search for "Product Personalizer Shopify" + [feature, review, limitation, tutorial]

## Output Format

Write a markdown file with sections for each area above. Include URLs and direct quotes where relevant. Mark any dead links or unverifiable claims.
