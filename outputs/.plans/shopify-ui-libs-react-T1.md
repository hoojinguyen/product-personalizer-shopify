# Researcher 1: Shopify Polaris & App Bridge Integration

**Objective**: Investigate the current state of Shopify Polaris and its integration with `@shopify/app-bridge-react`.

**Key Areas to Cover**:
1. **Polaris Features**: What are the main benefits of using `@shopify/polaris` for a Shopify Admin app?
2. **App Bridge Integration**: How does Polaris work alongside `@shopify/app-bridge-react`? Are there specific navigation components (like App Bridge's `<NavMenu>`) that require Polaris?
3. **Tech Stack Compatibility**: The target project uses React Router v7 and Vite. Are there any known issues, configurations, or best practices for using Polaris with this modern stack?
4. **Design System Alignment**: What are the business and user experience trade-offs of adhering strictly to Shopify's design language?

**Tools to use**: `web_search` for Polaris docs, App Bridge React docs, and community discussions about Polaris with Vite/React Router.
**Output**: A detailed markdown report with findings and source URLs.
