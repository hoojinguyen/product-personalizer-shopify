# Mission: Product Personalizer Shopify App — End-to-End Flows

## Why
Ship features, debug issues, and review PRs confidently on this codebase by understanding every flow from storefront buyer interaction through to manufacturing fulfillment — including how Shopify's platform primitives (metafields, Cart Transform, webhooks, app proxies) are wired together behind the scenes.

## Success looks like
- Trace a buyer's journey from landing on a personalized product page → customizer interaction → cart → checkout → order creation → fulfillment download, identifying the code path at each step
- Explain how Templates propagate Personalization Configs to products via metafields
- Explain how upcharge pricing is injected into the cart via Cart Transform
- Explain how order webhooks trigger Manufacturing Dataset compilation
- Confidently navigate the admin dashboard routes and understand what each settings panel controls

## Constraints
- Experienced with React/Remix and Prisma — skip basics on those
- New to Shopify platform concepts (metafields, app extensions, Shopify Functions, app proxies, webhooks) — teach these as encountered
- No time constraints or learning format preferences

## Out of scope
- Shopify theme Liquid templating (beyond what the app extension injects)
- Shopify Partner dashboard / app submission process
- Payment processing internals
